D4 — 학습 가치망 스코핑 리포트

PIMC 리프 평가기를 학습망으로 · 코드 근거 3중 조사(통합·알고리즘·파이프라인) 종합 · 2026-07-16

D4는 진짜 천장을 구조적으로 올릴 유일한 레버지만, 천장은 휴리스틱보다 나은 라벨이 있을 때만 오르고, 풀룰+폭탄 학습 정책은 미개척·패리티 확률 높음. 좋은 소식: 우리 아키텍처가 Fork A(리프 교체)를 거의 공짜로 시도하게 해줌 — 리프 값은 함수 1개·호출 2곳에서만 나오고, 시뮬·오라클·벤치가 이미 헤드리스로 학습데이터를 만든다. 결론: 몇 주를 걸지 말고, ~1주짜리 오프라인 실험으로 먼저 디리스크.

두 갈래 — 같은 베팅이 아니다

Fork A — 리프 평가기 교체 안전·첫 단계

휴리스틱 롤아웃 대신 V(world,seat)→EV 한 번 추론. PIMC/α-μ/결정화기 전부 재사용.
  • 이득: 롤아웃 노이즈 제거 + 리프당 비용 ~1000× 절감 → 같은 예산에 세계수 10배 + α-μ 파레토 비교 탈노이즈(팀의 "α-μ 노이즈 한계" 직격)
  • 한계: 전략융합은 못 고침(세계별 완전정보값+평균이 곧 융합). 휴리스틱 라벨로 학습하면 휴리스틱을 복제만 → 천장=휴리스틱
  • 천장이 오르려면 더 강한 라벨(오라클 값 / PIMC 자기대국 반복)

Fork B — 학습 정책이 PIMC 대체 XL·후순위

DouZero DMC / PerfectDou PTIE. 탐색 없이 한 번 추론.
  • 이득: 전략융합을 구조적으로 제거(DouDizhu서 인간급 입증)
  • 비용: PIMC 투자 폐기 + 풀 티츄 RL 환경(파트너십·폭탄·봉황/개/소원·교환·용양도·티츄콜) 필요
  • 현실: 티츄 논문들은 폭탄 삭제 단순룰서 아마추어 정체(Müller +21.2 "명백한 실수"·Wyss 아마추어). 풀룰+폭탄은 미개척 = 지도 밖

우리 코드에 어떻게 붙나 — 시임이 이상적이다

  • 리프 값 = 함수 1개, 호출 2곳 — Pimc.Rollout(Pimc.cs:14–23)가 결정화 세계를 끝까지 플레이해 관측팀 점수차 반환. 호출부는 PimcAgent.cs:182(후보별)·:222(패스).
  • after-state를 평가하므로 V(GameState world, int observerSeat)→double가 정책/Q 헤드 없이 그대로 꽂힘(이상적 PTIE 리프 형태).
  • 수술 최소: 인터페이스 1개(IWorldEvaluator) + 플래그 1개(off면 비트불변, 기존 Use* 토글과 동일) + 호출 2곳 교체. Pimc.Rollout은 폴백 겸 학습라벨 생성기로 보존.
  • 이미 가진 것: 순수 C# 시뮬(GameEngine·GameDriver, UnityEngine 의존 0)·결정화기·합법수·미러드 벤치(PimcBench.RunMirrored) → dotnet으로 헤드리스 학습데이터 생성.
  • 지연: 넷 리프 ~10–100µs(롤아웃 대비) → 24세계×20후보 ≈ 24ms, 900ms 예산에 세계수 10배 여유.
  • 런타임: 손코딩 C# matmul(~30줄, 패키지 0) 권장 — Sentis/ONNX 불필요(이 입력 크기엔 과잉). 인코더 ~300–600 float(56카드 멀티핫+스칼라).

디리스크 사다리 — 몇 주 걸기 전에 게이트

디리스크 우선: 오프라인 리프 A/B(①) → 오라클 상한 탐침(②) → 통과 시에만 학생 넷 증류(③). 콜 예측 헤드는 직교·확실한 별개 승리.

★ 넷과 무관한 확실한 승리 — 콜 예측 헤드: 라운드끝 보상 RL은 "티츄 절대 안 부름"으로 붕괴(문헌 확인). 별도 "이 손이 먼저 나갈까?" 보정 헤드(~17입력 MLP, BSW 로그 or 자기대국서 노트북 시간)면 Müller가 +10점/R 보고. 문서화된 롤아웃 콜 천장을 직격하는, D4에서 가장 확실한 클린 윈. ⚠️BSW 로그는 라이선스 회색지대(자기대국 라벨로 대체 가능).

비용 · 현실적 이득 (정직하게)

  • 비용 — 카드게임 RL은 GPU 아닌 CPU-시뮬 바운드. Fork A 데이터생성=기존 C# 시뮬 공짜(휴리스틱 라운드 sub-ms). MLP 학습=아무 GPU/CPU서 몇 시간. Fork A 첫 A/B ~1주, 라벨반복+튜닝+티어 몇 주. Fork B=수주~수개월(참조 티츄 논문 16~32코어 5~8일).
  • 현실적 이득 — Fork A(휴리스틱 라벨)=탈노이즈+세계수↑로 원리상 우월하나 이득은 modest, 벤치 통과 필수(팀 역사=사람눈 개선이 벤치서 회귀 상습). 전략융합 못 고침. 풀룰 학습 정책 = 미개척, 몇 주 써서 기존 PIMC와 패리티~이하가 가장 유력한 결과.

권고 — 몇 주 걸지 말고 먼저 디리스크

아키텍처가 Fork A를 거의 공짜로 만든다(리프=함수1·호출2, 데이터생성 기존, matmul 무패키지). GO: ~1주 오프라인 리프 A/B(①) + 오라클 천장 탐침(②) + 콜 예측 헤드(직교·확실). DEFER: 학습 정책 넷(③)은 오라클 게이트 통과 시에만. 근거: 휴리스틱 라벨 넷은 오늘 천장을 복제만·리프는 융합 못 고침·풀룰 정책은 패리티 리스크. 오라클 탐침이 크게 이길 때만 몇 주 투자할 가치.

당신이 정할 것

경로: Fork A(리프 디리스크) 먼저 확정, Fork B(정책넷)는 오라클 게이트 뒤로 — 지금 B 시작 안 함.

라벨: 휴리스틱 자기대국(값쌈·복제만) vs 오라클/PIMC 반복(천장↑·비용·연구리스크).

콜 헤드 지금? 노트북 시간·+10/R·가장 확실 — BSW 회색지대 감수 or 자기대국 라벨.

런타임: 손코딩 matmul(권장·무의존) vs Sentis.
