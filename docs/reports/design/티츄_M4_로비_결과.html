티츄 M4 — 로비 · 출시 주소 · 거부 메시지 결과

2026-10-15 ~ 10-16 · 브랜치 feat/mp-m4 · 스펙 docs/superpowers/specs/2026-10-15-mp-m4-lobby-design.md · 서버·프로토콜 변경 없음(클라이언트만)

결론: 출시를 막던 클라이언트 쪽 문제 세 가지를 풀었습니다. ① 출시 빌드에서도 온라인 대전에 들어갈 수 있는 길이 생겼습니다(주소가 비어 있으면 "준비 중"). ② 대기 화면이 4칸 자리와 AI 충원 카운트다운으로 바뀌었습니다. ③ 서버가 보내는 영문 거부·중단 사유를 한국어 안내로 바꿨습니다. 테스트와 실기 확인(에디터 + S23)을 통과했습니다.

1. 확정된 결정

결정내용미룬 것
로비 = 대기 화면 정식화(A안)서버가 이미 보내는 정보(대기 인원·AI 충원 남은 초·붐빔 순번·방 접속 수)를 4칸 자리와 카운트다운으로 보여 줌닉네임(B안, 프로토콜·UGC 부담), 초대코드 친구방(C안, 새 서버 기능) → 출시 후
출시 주소 = 빌드에 고정(1안)Resources/ReleaseServer.asset 하나에 주소. 비어 있으면 출시 빌드는 "온라인 대전은 준비 중입니다"원격 설정(gh-pages server.json)·출시 빌드 주소 입력은 기각
구조 = 테이블 위 오버레이(가안)접속·대기·게임·재접속은 지금처럼 RoundBootstrap 한 흐름. 오버레이 그리기만 LobbyOverlayView로 분리메뉴의 별도 로비 화면(나안): 연결 소유권이 씬 경계를 넘어 M5 흐름을 다시 뜯어야 해서 기각

실기 확인 (2026-10-16, 에디터 + S23 개발 APK, 같은 Wi-Fi 로컬 서버)

#항목결과
1혼자 대기 → 칸 1개("나") + AI 충원 카운트다운 → 0초에 시작✅
2에디터와 폰 동시 접속 → 두 화면 모두 칸 2개✅
3방 상한 1 서버에서 판 진행 중 새 접속 → "서버가 붐빕니다 · 대기 순번 1", 칸 숨김✅
4판 도중 폰 Wi-Fi 끊기 → "연결이 끊겼습니다" 화면 → 다시 켜면 같은 자리 복귀✅
520초 초과 직후 카드 내기 → 토스트생략 — 20초가 지나면 카드를 낼 수 없어 사람 손으로는 만들 수 없는 경로(네트워크 지연 때만 발생). 단위 테스트로 고정
6대기 중 [취소] → 메뉴, 알림 없음✅
7서버를 끈 상태에서 접속 → 메뉴 "서버에 연결할 수 없습니다"✅

칸을 숨기는 장면(3·4번)에서 제목과 설명 사이가 비어 보일 수 있다는 리뷰 지적이 있었으나, 실기에서 문제로 보지 않았습니다.

4. 어떻게 만들었나

계획 4개 태스크를 한 세션에서 TDD로 진행했고(Native 실행), 끝에 새 리뷰어(가장 강한 모델)가 브랜치 전체를 리뷰했습니다. 결과는 Critical 0 · Important 0 · Minor 6이었고, Minor 중 하나(라운드가 끝나 버려진 수에 "AI가 대신" 문구가 뜸)는 사실과 다른 안내라 Important로 올려 테스트를 먼저 깨뜨린 뒤 고쳤습니다.

진행 중 내린 결정

결정틀렸을 때 비용
워크트리 대신 기존 체크아웃의 브랜치에서 작업(새 워크트리는 Unity 전체 재임포트 수십 분)작업 중 main 체크아웃이 브랜치에 묶임 — 작업 트리는 깨끗
방 배정 장면의 칸 수·문구는 스펙 표 그대로(배정 직후 같은 프레임에 시작해서 거의 보이지 않음)한 프레임 어색한 문구
출시 주소에 scheme을 빼면 ws://로 보완되는 기존 동작 유지 — M2b에서 wss://를 명시M2b에서 주소를 wss://로 쓰면 무관
메뉴 버튼 배선(OnFriendRoom)은 단위 테스트 대신 OnlineEntry 테스트 + 실기로 확인배선 실수는 실기에서 발견 — 실기 통과
출시 주소가 비어 있음을 고정하는 테스트는 M2b에서 일부러 깨짐없음(주소를 넣을 때 갱신하라는 신호)

5. 남은 일

M2b(클라우드 배포)에서 할 일: ReleaseServer.asset의 address에 wss://…kas328.com/… 주소를 넣고, Release_server_asset_ships_and_is_empty_until_M2b 단언을 갱신한 뒤 출시 AAB를 다시 빌드합니다. 도메인 kas328.com은 10/16에 구매했고 DNS는 Lightsail DNS 영역에서 관리합니다. 서버 주소 레코드는 그 영역에 추가합니다.

실기에서 나온 피드백 (M4 범위 밖 → 다음 증분 M5.1 후보)

피드백방향
Wi-Fi를 끊었다 돌아오면 차례 20초가 처음부터 다시 시작됨 → 시간 벌기로 악용 가능서버가 차례 시작 시각을 기억해 재접속해도 남은 시간부터 이어서 셈(M5에서 이월로 적어 둔 항목)

리뷰에서 이월한 Minor

  • 로컬 AI 대전에서 세션이 중단돼도(버그일 때만 나는 경로) "서버 오류로 판이 중단되었습니다" 문구가 뜸.
