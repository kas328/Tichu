한 줄 요약: 차례 시간은 이제 어떤 경로로도 20초로 되돌아가지 않고, 다른 사람 차례의 남은 초가 그 사람 이름표 옆("왼쪽 · 12초")에 보인다. 자동 테스트·최종 리뷰 완료, 실기는 출시 직전 배치로 미룸.

1. 확정된 결정

  1. 한 결정에 마감 하나. 차례·용 양도는 처음 물을 때 마감을 정하고, 다시 물어도 남은 초만 준다.
  2. 되돌림 없음 — 멈춤 복귀 포함. 브레인스토밍에선 "혼자 판 멈춤 복귀는 새 20초"로 정했으나, 스펙 리뷰에서 사용자가 "다시 돌아가는 것 자체가 필요 없는 기능"이라 뒤집었다. 큰 티츄·교환의 멈춤 복귀 예외도 함께 제거. 단, 사람에게 한 번도 묻지 않은 질문은 돌아와 처음 물을 때 시계가 시작된다(되돌림이 아니라 첫 시작).
  3. 남의 남은 초는 이름표 옆. 내 차례는 기존대로 아래 가운데 "남은 시간 N초".
  4. 프로토콜 불변. 이미 있던 SecondsLeft·AskId 를 다른 좌석 축약판에도 채울 뿐 — 예전 앱·예전 서버와 호환.

  • Tichu.Net/Awaiting.cs (미러) — Redacted() 에 AskId·SecondsLeft.
  • Tichu.Server/Matchmaking/Room.cs — 재접속 스냅샷 남은 초 차감(원본 보관·0 하한).
  • Presentation/ViewModel/TableViewModel.cs — SeatSecondsLeft(seat), 같은 질문 재전송 무시, 재접속 시 해제.
  • Presentation/Views/RuntimeTableView.cs — SeatLabel, 이름표 매 프레임 조립, Overflow.
