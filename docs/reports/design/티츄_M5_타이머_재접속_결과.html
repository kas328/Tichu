결론: 잠수하거나 연결이 끊긴 사람 때문에 판이 멈추거나 끝나지 않습니다. 시간을 넘기거나 끊기면 AI가 그 자리를 이어서 플레이하고, 같은 기기로 돌아오면 자기 자리를 되찾습니다. 테스트와 실기 확인(에디터 + S23)을 모두 통과해 main에 들어갔습니다. 낯선 사람과 매칭하기 위한 출시 전 필수 조건이 채워졌습니다.

1. 무엇이 바뀌었나

플레이어가 보는 것

  1. 남은 시간: 테이블 아래쪽 가운데에 내 차례 남은 초가 표시됩니다. 큰 티츄·교환은 단계가 시작되는 순간부터 네 명 모두 같은 20초를 셉니다(다른 사람의 답을 기다리지 않음).
  2. 시간 초과: 20초를 한 번이라도 넘기면 그 자리는 AI가 플레이합니다. 화면에 자리 비움 — AI가 대신 플레이하는 중 배너와 [돌아가기] 버튼이 뜹니다.
  3. 다른 사람 표시: AI가 맡은 좌석은 이름 뒤에 (AI)가 붙습니다(예: 파트너(AI)).
  4. 연결이 끊기면: 앱이 1·2·4·8초 간격으로 최대 2분 동안 다시 접속을 시도합니다. 성공하면 같은 자리, 같은 점수로 돌아갑니다. 앱을 껐다 켜도 같은 기기라면 진행 중인 판으로 돌아갑니다.

3. 어떻게 만들었나

9개 태스크를 태스크마다 새 구현 에이전트 + 독립 리뷰로 진행했고, 브랜치 전체 리뷰와 실기 피드백 수정 뒤 재검토를 한 번씩 더 했습니다. 동시성이 걸린 원격 좌석·방 태스크는 가장 강한 모델이 리뷰했고, 리뷰에서 나온 경합(깨움 유실, 시간 초과 경계의 답 누수, 끊김 직전 답 유실 등)은 모두 고쳤습니다(대부분 테스트로 재현했고, 테스트로 닿지 않는 좁은 구간은 코드 검토로 확인).

잠금 순서는 방 → 좌석 한 방향으로 고정했습니다. 좌석은 자기 잠금 안에서 방을 부르지 않으므로 교착이 없습니다.

진행 중 내린 결정

결정틀렸을 때 비용
큰 티츄·교환 답에는 질문 번호를 붙이지 않음(서버가 묻기 전에 미리 답할 수 있어야 하므로). 대신 "이번 라운드에 이미 정함" 검사로 보호두 종류의 늦은 답 보호가 약간 약함 — 라운드 단위 검사가 상한
자리 비움 좌석은 다시 묻지 않고 대리 AI가 바로 플레이(질문 창이 깜빡이지 않게). 상태는 뷰의 자리 비움 표시로 보임자리 비운 사람은 [돌아가기] 전까지 질문을 받지 않음(의도)
재접속·연결 상태 변경을 방 잠금 안에서 원자적으로(계획은 "가능하면 잠금 밖")앞으로 좌석이 방을 역호출하면 교착 — 잠금 순서를 문서화
모두 끊겨 멈췄다가 돌아온 좌석은 큰 티츄·교환에서도 시간을 새로 받음. 화면도 서버가 준 초를 따름혼자 돌아온 사람이 원래 창보다 최대 20초 더 받음
에디터 Play 모드 수동 확인을 실기 체크리스트로 이동UI 배선 버그가 실기 때 드러남 — 실기 통과로 해소

4. 남은 일

다음 큰 일: 클라우드 배포(M2b). AWS Lightsail 서울 인스턴스 할당량은 10/12 승인됐습니다. 인스턴스 생성과 도메인 구매는 요금이 나가므로 나중에 한 번에 진행하기로 했습니다.
  • M5.1 / 출시 전 다듬기(드문 경우, 리뷰에서 이월): 재접속 시 차례 시계가 다시 시작됨, 작은 티츄 직후 경합으로 답이 한 번 튕길 수 있음, 대리 AI의 교환 고정 정보가 오래됨, 대기열에 3명 있을 때 재접속하면 새 판이 시작될 수 있음, 카운트다운 지연, 중복 접속 로그 중복, 거부된 액션이 자리 비움을 해제함.
  • 도메인: 도메인 케이스가 아직 미배정이라 업데이트 회신이 필요합니다(초안 있음, 승인 후 전송).
  • M4: 출시 빌드에 서버 주소 고정, 로비 UI.
  • 출시 준비: 카드 아트, 스토어 자산, 온라인 대전 추가에 따른 Data safety 재신고.
