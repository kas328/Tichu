티츄 게임 서버 구조 — 한 장으로 이해하기

M2b에서 만드는 것: 폰이 어느 네트워크에서든 wss://play.kas328.com에 접속해 다른 사람과 한 판을 끝까지 두는 환경

1. Lightsail이 뭔가요?

AWS(아마존 클라우드)가 월정액으로 빌려주는 리눅스 컴퓨터입니다. 서울에 있는 AWS 데이터센터 안에 가상의 컴퓨터 한 대를 만들고, 우리가 그 위에 원하는 프로그램을 올려 24시간 돌립니다.

🏠 비유: 내 PC에서 서버를 돌리면 PC를 끄는 순간 게임이 멈춥니다. Lightsail은 "전기·인터넷이 끊기지 않는 남의 건물에 내 컴퓨터를 한 대 빌려 두는 것"입니다. 내 PC는 꺼도 됩니다.

AWS에는 같은 일을 하는 EC2라는 서비스도 있습니다. EC2는 설정이 복잡하고 요금이 사용량에 따라 바뀝니다. Lightsail은 EC2를 쉽게 묶은 버전으로, 컴퓨터·고정 IP·디스크·데이터 전송량·방화벽·DNS가 한 화면에서 정액으로 관리됩니다.

우리가 고른 것뜻
서울 리전컴퓨터가 서울 데이터센터에 있음 → 한국 사용자와 거리가 가까워 반응이 빠름
Ubuntu 24.04 LTS컴퓨터에 깔 운영체제(리눅스). LTS = 장기 보안 업데이트가 보장되는 판
월 $7 플랜메모리 1GB · CPU 2개 · 디스크 40GB · 월 전송량 2TB
vCPU 한도신규 계정 보호용 제한이 0으로 걸려 있어서 AWS에 해제를 요청함(현재 검토 중)

2. 전체 그림 — 폰에서 게임 서버까지

3. 부품 하나씩

도메인 · DNS
사람이 읽는 이름 → 컴퓨터 주소(IP) 변환표
play.kas328.com → 13.x.x.x. 서버를 옮기면 이 표만 고치면 되고, 앱은 그대로입니다.
고정 IP
서버의 바뀌지 않는 인터넷 주소
기본 IP는 서버를 껐다 켜면 바뀔 수 있어서, 고정 IP를 붙여 DNS가 늘 같은 곳을 가리키게 합니다. 서버에 붙어 있는 동안은 무료입니다.
방화벽
들어올 수 있는 문(포트)만 열어 두는 경비
22(관리자 SSH)·80(인증서 발급)·443(게임)만 엽니다. 게임 서버 포트 7777은 바깥에서 아예 못 들어옵니다.
TLS · wss://
통신 암호화 (HTTPS의 그 자물쇠)
중간에서 패킷을 엿봐도 카드·행동이 안 보입니다. ws는 평문, wss는 암호문입니다.
Caddy (리버스 프록시)
앞문 담당. 암호를 풀어 안쪽 게임 서버로 넘겨줌
Let's Encrypt 무료 인증서를 알아서 받고 90일마다 알아서 갱신합니다. 우리는 설정 3줄만 씁니다.
Tichu.Server
우리가 만든 게임 서버 프로그램(.NET)
싱글플레이와 같은 core 코드로 규칙을 판정하고, 빈자리는 PIMC AI가 둡니다. 각 좌석에는 자기 손패만 보냅니다(치팅 방지).
systemd
리눅스의 프로그램 관리인
서버 프로그램이 죽으면 2초 뒤 다시 켜고, 컴퓨터를 재부팅해도 자동으로 켭니다.
SSH 키
서버에 관리자로 들어가는 열쇠 파일
C:\Users\user\.keys\에만 보관합니다(업로드 키와 같은 곳). 저장소에 넣지 않고, 잃어버리면 서버를 새로 만들어야 합니다.

4. 한 판이 진행되는 순서

  1. 접속 — 앱이 wss://play.kas328.com/ws?v=1로 연결합니다. v=1은 프로토콜 버전입니다.
  2. 버전 확인 — 서버가 앱 버전을 확인합니다. 다르면 "앱을 업데이트해 주세요"를 보내고 끊습니다(이번 M2b에 추가). 구버전 앱이 이상하게 동작하는 것을 막습니다.
  3. 대기실 — 접속 순서대로 좌석 0번, 2번을 받습니다(같은 팀). "기다리는 중 1/2"가 표시됩니다.
  4. 매치 시작 — 사람 2명이 다 차면 시작합니다. 좌석 1·3번은 서버의 AI가 둡니다.
  5. 진행 — 앱이 낸 수를 서버가 규칙으로 검사하고, 상태를 좌석별로 손패를 가려서 보냅니다.
  6. 종료 — 목표 점수(1000)에 도달하면 결과를 보내고, 서버는 새 대기실을 엽니다.
⚠️ 지금 단계의 한계: 서버 하나에 방 하나, 한 번에 한 판입니다. 판 도중에 한 명이 나가면 그 판은 끝납니다. 방 여러 개·랜덤 매칭은 M3, 나간 자리를 AI가 이어받거나 다시 접속하는 기능은 M5에서 만듭니다.

5. 코드를 서버에 올리는 방법 (배포)

PC에서 pwsh tools/deploy-server.ps1 하나를 실행하면 다음이 순서대로 일어납니다.

  1. 서버 프로그램을 리눅스용으로 빌드합니다(.NET을 통째로 포함해서 서버에 따로 설치할 필요가 없음).
  2. 압축해서 서버로 업로드합니다.
  3. 서버가 새 버전으로 바꾸고 재시작합니다. 30초 안에 정상 기동하지 않으면 직전 버전으로 자동으로 되돌립니다.
  4. PC에서 실제로 wss 접속해 대기실 응답이 오는지 확인합니다.
⚠️ 재시작하면 진행 중인 판이 끊깁니다. 그래서 자동 배포가 아니라, 판이 없을 때 사람이 직접 실행하는 방식으로 정했습니다.
