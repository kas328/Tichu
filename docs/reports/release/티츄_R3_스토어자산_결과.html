3. 스펙과 다르게 간 점

  1. versionCode 3 — 릴리스 빌드가 매번 +1 한다. 새 패키지의 첫 업로드라 값은 상관없다.
  2. Round·Legacy 아이콘은 한 장 — minSdk 26 이라 모든 기기가 적응형 아이콘을 쓴다.
  3. 스크린샷도 알파 없이 — Play 규격(24비트 PNG/JPEG)이 스크린샷에도 적용된다.
  4. "온라인 친구방" → "온라인 대전(자동 매칭, 빈자리는 AI)" — 구현된 기능 기준. 근거 없는 "전 세계에서 사랑받는" 문구도 뺐다.
  5. 스크린샷 06(온라인 대기 화면) 생략 — 로컬 서버가 필요하고 개발 빌드는 주소 입력칸이 찍힌다. 5장으로 Play 최소(2장)를 넘는다.
  6. AAB 는 실행 중 에디터에서 빌드 — 에디터 프로세스에 키스토어 환경변수 4개가 있는 것을 값 없이 확인한 뒤 같은 메뉴(Tichu/Build Release AAB)를 실행했다. 에디터를 닫을 필요가 없었다.
등록정보 주의: "■ 온라인 대전" 단락은 listing.html 에서 별도 블록으로 나눠 두었다(노란 안내 표시). M2b 서버 배포 뒤에만 자세한 설명에 붙인다. 간단한 설명에는 온라인 언급이 없다. — 최종 리뷰 지적 반영
