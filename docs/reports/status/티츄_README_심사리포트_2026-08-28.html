원인
스크립트는 core/tests → Assets/Tests/EditMode까지 비교하는데, 내가 어제 만든 CI 잡은 "테스트·벤치 하니스는 dotnet 전용이라 미러하지 않는다"며 src만 비교한다. 두 기준이 서로 다르다.
왜
README의 실행 명령은 두 개뿐인데 그중 하나가 면접관 손에서 빨간 실패를 낸다. 그것도 바로 위에서 "CI가 매 푸시마다 해시를 비교해 어긋남을 막는다"고 자랑한 파이프라인이다. 더 나쁜 건 -Check 없이 실행하는 경우 — Unity 전용 테스트가 조용히 덮이고 dotnet 전용 벤치 9개가 Unity 테스트 어셈블리로 복사된다.
수정
스크립트에서 tests 매핑을 제거하고(권장), CI mirror 잡이 -Check를 그대로 호출하게 바꿔 기준을 하나로 통일. 그러면 README·스크립트·CI 셋이 같은 말을 한다.
