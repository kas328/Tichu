# R4 정책 선언 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 비공개 테스트 트랙 공개에 필요한 App content 선언을 완비한다 — 살아 있는 개인정보처리방침 URL과, Play Console에 그대로 옮겨 적을 수 있는 확정 답변표.

**Architecture:** 방침 페이지는 `main` 이력과 분리된 `gh-pages` orphan 브랜치에 단독으로 산다(게임 소스와 내부 설계 문서를 웹에 노출하지 않기 위해). Play Console 입력은 사람만 할 수 있으므로, 이 계획의 산출물은 "무엇을 답할지"를 근거와 함께 확정한 문서다.

**Tech Stack:** 정적 HTML · GitHub Pages · git orphan 브랜치

**설계 스펙:** `docs/superpowers/specs/2026-08-20-r4-policy-design.md` (커밋 `3b71258`)

- [ ] **Step 7: 작업 브랜치로 복귀**
