티츄 M2 실기 검증

친구방 WebSocket 서버(같은 Wi-Fi) · 에디터 1 + S23 1 = 인간 2명(좌석 0, 2, 같은 팀) · 빈자리는 서버 PIMC

준비

  • PC IP 확인: 명령 프롬프트에서 ipconfig → 무선 LAN 어댑터 Wi-Fi의 IPv4 주소.
  • S23과 PC가 같은 Wi-Fi에 있어야 한다.
  • S23에는 새 Development Build APK(Build/TichuMaster-dev-arm64.apk)를 설치한다. 예전 빌드는 접속 화면이 없다.
  • 서버 명령(레포 루트): 
    dotnet run --project core/src/Tichu.Server -- --seats 0,2 --target 200
  • 서버는 매치당 1회용 — 매치가 끝나거나 누가 끊기면 종료되므로, 다음 항목 전에 다시 실행한다.
  • 처음 실행하면 Windows 방화벽이 묻는다 → 개인 네트워크 허용.
