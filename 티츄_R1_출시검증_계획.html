전체 그림

Google Play 출시 = 5트랙

검증(R1)이 전부의 관문. 검증 안 된 빌드에 스토어 자산·서명·정책을 붙이는 건 무의미하니, R1부터 상세 설계한다.

트랙핵심주 담당순서
R1 검증D6 실기기 게이트 + 미확인 부채 플레이테스트 → Phase 1 종료🧑 당신 위주지금
R2 빌드/서명Release keystore·AAB·타겟 API·R8·권한 감사내가 설계R1 후
R3 스토어 자산아이콘·피처그래픽·스크린샷·스토어 문구🧑 + 스캐폴딩R2 병행
R4 정책개인정보처리방침·Data safety·콘텐츠 등급·64bit내가 초안R3 병행
R5 배포Play Console 계정·내부→비공개→프로덕션·사전출시보고서🧑 제출최종

R1 검증 — 상세 설계

S23 한 대(플래그십)만 있는 현실을 반영해 세 부분으로 나눈다.

a

성능 게이트

S23 스모크 · 저사양 미대응

제품 결정 — 저사양 미대응. 저사양 사용자 비중이 미미해 성능 게이트를 현대 중급+ 기기 기준으로 단순화. 보유한 S23 스모크가 곧 게이트다.

항목언제방법
DoD#2 60fps 스모크(현대 기기)R1S23 Dev Build + FpsOverlay 상시 녹색(≥55), 적색 스파이크 0
저사양 60fps 확정범위 제외R5 Play 사전 출시 보고서는 무료 참고자료로만(게이트 아님)
  • 풀매치(1000점) 크래시 0으로 완주
  • 전 구간 FpsOverlay 녹색 유지 · 적색 스파이크 없음
  • DoTween 애니(플레이 팝·차례 펄스·결과 팝) 프레임 드랍 체감 없음
  • 여러 라운드 연속 시 GC 스파이크 끊김 없음(D3 풀링)
⚠️
첫 관문: D6 시점 APK 빌드는 미수행. Unity Hub에 Android Build Support(SDK·NDK·JDK) 설치부터 확인해야 한다.
b

미확인 AI 부채 통합 체크리스트

핵심 작업량 · 1패스

채택했지만 실기 미확인인 변경을 하나의 가이드 체크리스트로 통합해, S23 Expert 집중 플레이테스트 1패스로 전수 관찰한다. 기존 인터랙티브 대시보드를 이 항목으로 확장.

항목라이브에서 무엇을 보나상태
③′ 확실승자 리드{10,A}에서 A 먼저 리드하고 나가는가(10 먼저 리드해 밟히지 않는가)배선완료·미확인
① 봉황콤보 보존봉황을 싱글로 헛쓰지 않고 자연 승수로 밟는가미확인
#4 라지티츄 지원파트너 티츄 콜 시 최고카드 교환·밟기 금지·먼저 나가기 금지로 협조하는가미확인
#4c 살리기콜한 파트너 못 나갈 상황이면 살려주는 탈출을 하는가미확인
C1 교환핀(간접) 교환 후 넘긴 카드 좌석을 아는 듯한 플레이미확인
07-15 · D3 구조보존리드스트레이트/트리플/연속페어 깨는 싱글 리드를 회피하는가미확인
콜헤드(Grand/Small)(재확인) Grand 더 자주 · 이상한 Small 감소07-24 확인됨

+ 일반 스모크

  • 4난이도(쉬움/보통/어려움/전문가) 각각 시작·정상 동작
  • 풀매치까지 크래시 0 · 모든 룰 인터랙션(폭탄·용·개·마작 소원·티츄/큰티츄·1-2 피니시) UI 정상
  • D5.1 사운드: 버튼음·볼륨 패널·백그라운드 음소거 정상

이번에 확정된 두 가지

정해진 결정

결정 1 · 성능

저사양 미대응

저사양 비중이 미미 → 성능 게이트를 S23(현대 기기) 60fps 스모크 하나로 단순화. 저사양 60fps 확정은 범위 제외(R5 사전출시보고서는 참고자료로만).

결정 2 · 이름

게임명 = Tichu Master

'Tichu' 유지로 검색 발견성을 살리고 'Master'로 구분(TichuOne류). Play에 동일명 앱 없음(이름 확보 OK). ⚠️ 상표 회피가 아닌 유지 — 발견성↔상표노출 트레이드오프 수용. 인게임 콜 명칭은 그대로.
